# TN_QMH_Helper_Loop
LabVIEWのQueued Message Handler(QMH)のヘルパーループです。メッセージキューはNIのQMHのテンプレートにあるもの(メッセージ：文字列、データ：バリアント)のものを前提とします。

LabVIEWバージョン：2026 Q3

使い方
- Activate Helper Loop.viを呼び出してHelper Loopを動的に呼び出します。ここで指定したMHL Queueに指定したメッセージ+データを指定した周期でエンキューします。周期処理の停止はこのVIで出力したHelper Loop Queueを使用します。
- Change Period of Helper Loop.viでエンキューの周期を変更できます。周期を変更した場合、変更したタイミングから周期で指定した時間経過後に最初の周期処理が行われます。
- Close Helper Loop.viを呼び出すと、周期処理を終了します。

注意
- 周期処理にかかかる時間 >= 設定周期 の場合を想定していません。
- Activate Helper Loop.viを呼び出すたびにヘルパーループを動的に呼び出し、Close Helper Loop.viで毎回ヘルパーループを終了しています。呼び出しや終了の時間が気になる場合は要注意です。
- ヘルパーループを止めずにMHLを終了することを想定していないので、MHLを終了するときに実行中のヘルパーループを止めてください。たぶん、MHLのメッセージキューを破棄したあとにヘルパーループでTimeoutになるとエンキューでエラーが発生してヘルパーループが止まると思いますが、未確認です。タイムアウトが-1になっている場合はずっと動くことになります。

ここではメッセージキューのメッセージはSystem文字列を前提としています。メッセージ文字列をUTF-8にする場合は、MHL Queueの変更や、メッセージ文字列の型の変更、ヘルパーループ内のエンキュー(エラーケース)の文字列の型の変更などを行って下さい。
