# TN_QMH_Helper_Loop
LabVIEWのQueued Message Handler(QMH)のヘルパーループです。メッセージキューはNIのQMHのテンプレートにあるもの(メッセージ：文字列、データ：バリアント)のものを前提とします。

LabVIEWバージョン：2026 Q3

使い方
- Start Periodic Enqueue Message.viを呼び出してHelper Loopを動的に呼び出します。ただし、使っていないヘルパーループが存在する場合はその中の1つを再利用します。ここで指定したMHL Queueに指定したメッセージ+データを指定した周期でエンキューします。周期処理の停止はこのVIで出力したHelper Loopクラスを使用します。
- Change Message Data.viでエンキューするデータを変更できます。周期を変更した場合、変更したタイミングから周期で指定した時間経過後に最初の周期処理が行われます。
- Change Message.viでエンキューするメッセージを変更できます。周期を変更した場合、変更したタイミングから周期で指定した時間経過後に最初の周期処理が行われます。
- Change MHL Queue.viでエンキューする先のキューを変更できます。周期を変更した場合、変更したタイミングから周期で指定した時間経過後に最初の周期処理が行われます。
- Change Period.viでエンキューの周期を変更できます。周期を変更した場合、変更したタイミングから周期で指定した時間経過後に最初の周期処理が行われます。
- Stop Periodic Enqueue Message.viで周期的エンキューを停止します。停止の際にヘルパーループを終了してリソースを破棄するか、再理療できるようにヘルパーループを残すかを選択できます。デフォルト設定ではヘルパーループを残します。
- Stop All Helper Loops.viを呼び出すと、すべてのヘルパーループを終了し、リソースを破棄します。アプリケーション終了時に利用することを想定しています。

注意
- 周期処理にかかかる時間 >= 設定周期 の場合を想定していません。MHLキューにデータがたまらないように注意してください。
- アプリケーションを終了するときは必ずStop All Helper Loops.viなどでヘルパーループも終了するようにしてください。

ここではメッセージキューのメッセージはSystem文字列を前提としています。メッセージ文字列をUTF-8にする場合は、MHL Queueの変更や、メッセージ文字列の型の変更、ヘルパーループ内のエンキュー(エラーケース)の文字列の型の変更などを行って下さい。
